# 0.3.1

Исправлен сбой при запуске AI Conflict на Arma Reforger 1.9.0.37. В версии 0.3.0 модуль `Game` не компилировался из-за устаревшего имени перечисления в двух пресетах анимации. [Ошибка #100](https://github.com/Ishafel/Arma-Reforger-AI-Conflict/issues/100)

На штатном Arland после исправления Workbench и dedicated server загрузили `Game`. Полный Workbench Validate остановился при инициализации Steam. Запуск матча до готовности отрядов остался непроверенным из-за недоступности сетевого сервиса игры.
