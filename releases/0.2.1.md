# 0.2.1

24 октября 2026 года. Исправления после `0.2.0`.
Код релиза — тег `0.2.1`, commit `498fda7`, после слияния

## Исправления

- **Публикация сценариев в Workshop.** Устранены 21 превышение лимита
  50 символов в 16 заголовках: 20 русских/английских переводов и один ключ
  локализации с `#`. Теперь все 82 собственных заголовка, включая setup,
  проходят проверку 246 raw/RU/EN значений. Максимальная длина — 50.
- **Краткие названия Co-op.** Длинные имена используют `WCS+RHS`, короткие
  обозначения стороны и `[M]`/`[H]` для средней/сложной сложности. Карта,
  контент, режим и сторона сохраняются; ранее допустимые имена не изменены.
  Один длинный ключ заменён коротким на основе прежнего string-item GUID.
  Resource GUID, пути, режимы, сложности и все 758 item GUID сохранены.
- **Защита генерации.** Генератор отклоняет имена длиннее 50 символов;
  добавлены общий аудит и граничные проверки 50/51 для ключей, переводов
  и literal names. Source и runtime-таблицы локализации согласованы.

## Как повторить публикацию

В поле Version укажите **`0.2.1`**. Workshop принимает только три числа
через точку без буквенных суффиксов; `0.2.1a` для версии пакета недопустим.
Старый Git-тег `0.2.1a` заменён тегом `0.2.1`.

Переоткройте/обновите ресурсы Workbench и начните новую публикацию.
Сначала обновите **AIConflictCore**, затем сценарные addons: прежний Core
не содержит нового короткого ключа. Очередь автоматических повторов
использует старые метаданные.
