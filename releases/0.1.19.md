# 0.1.19

Краткие release notes для Workbench:

- Добавлены сценарии «Север Эверона» для обычной игры и RHS: две HQ и шесть точек захвата.
- Ускорен поиск площадок автономного строительства: проверки продолжаются между обновлениями, повторная работа сокращена, финальные проверки получают резерв квоты. Проверки безопасности размещения сохранены.
- Захват баз ускорен втрое относительно штатного времени при одинаковых условиях.
- Улучшены проверки места появления пехоты и восстановление застрявших маршрутов.
- Сценарии и интерфейс переведены на русский и английский с выбором по языку клиента.
- Исправлены метки атаки у отрядов на пополнении; добавлен статус пополнения.
- Упрощена навигация редактора экипировки, добавлен подбор совместимого запасного магазина.

Проверки и ограничения выпуска исходников:

- Перед релизом шесть профильных static-аудитов (`GroupMapMarkers`, `InfantryRecruitment`, `EveronNorth`, `Localization`, `ScenarioHeaders`, `RuntimeLauncher`) — PASS. Проверки строительства и терминальный Workbench Validate/Compile описаны в сохранённых отчётах.
- В изолированном baseline строительства за 15 минут не было размещений на HQ. На окончательной версии первое размещение на авиабазе произошло через 2:02 от потребности; лёгкий автопарк — через 4:30, большие казармы — через 9:04. Пригодность всех площадок и универсальное время строительства не установлены.
- Сохранены прежние два failures `AI_COMMANDER_UI_STATE`. Полный runtime gate строительства остаётся FAIL из-за SCRIPT E в остановленных логах и неполной матрицы типов/фракций. Ошибки не подавлялись.
- NOT RUN для окончательной оптимизации строительства: client/JIP, RHS runtime, ручная визуальная проверка и отдельные runtime-инъекции смены ownership/строительства игроком во время checkpoint. Packaged Workshop validation и публикация через Workbench не выполнялись.
- При подготовке этого коммита меняется только документация; compile/runtime повторно не запускались. Статус ACCEPTED не присваивается.

Подробности: [проверки](../docs/TESTING.md), [измерения строительства](../docs/CONSTRUCTION_SPEED_20260919.md), [Север Эверона](../docs/EVERON_NORTH.md).
