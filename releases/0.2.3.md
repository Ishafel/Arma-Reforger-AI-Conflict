# 0.2.3

24 октября 2026 года. Изменения после последнего GitHub-релиза **0.2.0**,
включая исправления, ранее описанные в 0.2.1 и 0.2.2.
Код основан на main после слияния
[PR #71](https://github.com/Ishafel/Arma-Reforger-AI-Conflict/pull/71),
[PR #73](https://github.com/Ishafel/Arma-Reforger-AI-Conflict/pull/73) и
[PR #75](https://github.com/Ishafel/Arma-Reforger-AI-Conflict/pull/75).
GitHub Release публикует исходники; обновление модов в Workshop выполняется отдельно.

## Исправления

- **Первый Host Everon WCS + RHS.** После выбора операции загружаются выбранная
  карта и полный набор модов. Переход проходит через дополнительную загрузку
  главного меню и подготовительной сцены; повторно выбирать параметры не нужно.
  Исходные настройки Host удерживает движок. Загрузка карты, Listen, порт и
  готовность roster проверены; действие пароля и лимита игроков не подтверждено.
- **Выбранные время и погода.** Обычный игровой клиент сохраняет настройку
  окружения при переходе из подготовительной сцены. Исправлено чтение
  идентификатора целевого сценария из одноразового сохранённого выбора.
- **Общий вход AI Conflict.** Название доступно до загрузки Core. Первый
  Play/Host открывает настройку карты, контента, режима и сложности;
  подготовительная сцена ждёт выбора, а отмена возвращает в главное меню.
  Старые GUID сохранены для меню и серверных конфигураций.
- **Названия для Workshop.** Устранены превышения ограничения 50 символов
  в raw/RU/EN названиях сценариев. Длинные Co-op названия сокращены;
  генератор проверяет лимит. Идентификаторы ресурсов и локализации сохранены.
- **Подготовка каталога Workshop.** Добавлен Prepare-AICFWorkshopBundle.ps1:
  отдельная копия native bundle оставляет один вход AI Conflict, сохраняя
  содержимое пакета, идентификаторы и версию. Проверяются hashes и metadata.
  Это инструмент подготовки будущей публикации: уже опубликованный список
  сам по себе не меняется.
- **Проверка обычного клиента.** Терминальный Frontend launcher запускает
  главное меню без direct-connect и сохраняет фактический exit процесса.
  Dedicated Server/Client сохраняют прежние проверки готовности.

## Известные ограничения

**Native crash при завершении не устранён.** После смены набора модов
Play/Host может загрузить карту и успешно пройти проверки, затем упасть
при выходе с 0xC0000005. В последней серии первый из трёх WCS Play получил
этот сбой; два других Play и Host завершились нормально. Отдельные чистые
выходы не доказывают исправление нестабильного дефекта.

В опубликованной Workshop 0.2.2 остаются 82 записи: общий вход и 81 старый
вариант, иногда с ключами вместо переведённых названий. Hidden flag ресурсов
не очищает backend metadata. Подготовка нового каталога проверена локально,
но native uploader без регенерации manifest, приём backend и новое скачивание
пакетов — **NOT RUN**. Этот GitHub-релиз не обновляет установленные моды.

Также **NOT RUN**: packaged Play/Host после новой публикации, физический ввод
и визуальная оценка экрана, второй игрок/JIP, действительность пароля,
лимит игроков и длительный матч. Сохраняются прежние resource diagnostics
и известный native out-of-bounds длительного North Everon RHS прогона;
их устранение этим выпуском не заявляется.
