# Категории основного и второго оружия

## Быстрые слоты после появления

У двух длинноствольных оружий может совпадать native default quickslot.
`SCR_CharacterInventoryStorageComponent.InitAsPlayer` помечает этот default
инициализированным после первого предмета и пропускает вторую винтовку.
Оружие при этом присутствует в inventory и native WeaponSlotComponent, но
quickbar «2» пуст. Native component control с AK74M + SVD подтвердил этот
путь до исправления.

`Integration/AICF_WeaponQuickslots.c` после native InitAsPlayer дополняет
пропущенные привязки по `GetWeaponSlotIndex` для видимых оружейных мест.
Проверяет текущую attached entity и оставляет занятые slots, существующую
привязку оружия и turret context нетронутыми. При pControlled=false ничего
не добавляет. Inventory, recipe/schema, сохранение и RPC не меняются;
это локальное представление управляемого игрока. Отдельных callbacks нет.

Редактор показывает dropdown для обоих native `primary` slots. В кобуре,
гранатном слоте и креплениях остаётся прежний native контекст, внутри кармана —
прежние content categories. При переходе между primary slots категория сохраняется;
при смене вида категорий сбрасывается на «Всё оружие»/«Все предметы».
Source и поиск применяются вместе с категорией; кнопка очистки сбрасывает поиск
и dropdown. Названия локализованы RU/EN.

## Владельцы и классификация

`AICF_LoadoutWeaponCategories` фильтрует только прошедшие catalog/source/blacklist
и native slot проверки предметы. Полномочия сервера и формат рецепта не меняются.
Кэш `ResourceName -> int` не содержит entities и очищается в Close; он хранит
только классификацию, не разрешения. Неудачное получение preview не кэшируется.
ALL возвращает список без изменений; остальные категории строят подсписок за
один проход с сохранением порядка. `array.Remove` в Enforce переставляет элементы
и для этой операции не подходит.

Основа — `BaseWeaponComponent.GetWeaponType()` из закреплённого API 1.8.0.13.
`WT_RIFLE`, `WT_SNIPERRIFLE`, `WT_MACHINEGUN`, `WT_ROCKETLAUNCHER`,
`WT_GRENADELAUNCHER` определяют соответствующие категории. Подствольник не
переводит автомат в гранатомёты: используется тип оружия, не текущего muzzle.
Неизвестные primary weapons остаются в «Другое оружие» и «Всё оружие».

В enum движка нет отдельных DMR/SMG/shotgun типов. Уточнения принадлежат
`GetLoadoutWeaponCategory` соответствующего content profile, по resource path
или точному имени модели с границей `_`/расширения, без поиска по переведённой подписи:

- Core: M21 и семейство SVD — марксманские; остальные M14 и SKS — винтовки/карабины.
  Каталог `/Weapons/Shotguns/` зарезервирован для дробовиков.
- RHS: VSS и M38 SDMR — марксманские; остальные M27 IAR — пулемёты.
- WCS: G28, Mk 14 Mod 1, SVCh — марксманские; MP7, MPX, P90, PP19 — ПП;
  VPO185 — карабины. Остальное использует RHS/Core и native fallback.

Core не имеет зависимости от RHS classes/resources. Правила RHS/WCS подтверждены
выгрузкой установленного каталога; новые моды с другими путями могут потребовать
уточнения в своём profile. Категории не скрываются, когда в текущем источнике нет
подходящих предметов: UI показывает обычное сообщение о пустом результате.
В проверенных stock/WCS каталогах не было отдельных дробовиков/гранатомётов;
поддержка таких записей реальным runtime здесь не подтверждена.

## Проверки

Static audit сохраняет границы карманов, native compatibility перед фильтром,
scope primary, ALL и cleanup. Runtime fixture проверяет два primary slots,
неизменность ALL, разбиение всего списка без потерь/дубликатов/перестановок,
конкретные M21/SVD/M16/M60/RPG7/G28/DVL10/M38/M27/VSS/MPX/M203 и пересечение
с источниками. Метод штатной compatibility может переставлять элементы;
source intersection сравнивается по составу, порядок нового Filter — отдельно.

Ручной gate: в личном и отрядном редакторе переключить основное/второе оружие,
категорию, source и быстрый поиск; проверить «Очистить», переход в карман/кобуру/
обвесы и обратно, Apply/Undo, Close/reopen и длинные RU/EN подписи. Без ручного
клиента этот gate — NOT RUN. Команды и фактические результаты: [TESTING.md](TESTING.md).
