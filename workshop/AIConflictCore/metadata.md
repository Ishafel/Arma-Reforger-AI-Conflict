## Description

AI Conflict Core is the shared, map-independent foundation of an autonomous
US-versus-USSR war built on the stock Conflict systems.

Features:
- server-authoritative strategic planning and stable force slots;
- infantry orders, reinforcement and recovery;
- ground transport lifecycle and identity-safe cleanup;
- ticket and supply economy;
- replicated campaign summaries, allied map markers and strategic UI;
- structured AICF diagnostics for dedicated-server operation.

This is a dependency package. It does not add a standalone scenario and is not
intended to be enabled without a map integration addon. Install AI Conflict
Arland to use the current playable integration.
