# 0.1.16 — RHS Conflict on Everon

- **New scenario:** `AI Conflict RHS - Everon` brings autonomous RHS USMC
  versus RHS MSV Conflict to the full Everon island. The new
  `AIConflictEveronRHS` addon uses the official RHS mission and combines the
  existing RHS content profile with Everon's radio connectivity policy.
- **Base initialization fix:** a local compatibility adapter prevents the
  RHS callsign pool from running out when the island has more initialized
  bases than available callsigns. Base indexes remain unique; displayed
  callsign names may repeat through the stock lookup behavior.
- **Server and client launch:** use `-Variant EveronRHS` with
  `tools/Start-AICFRuntime.ps1` to load the complete dependency graph.
- **Scenario defaults:** both factions use AI commanders, each launch starts
  a fresh campaign, and the scenario starts at 08:00 with the same day/night
  acceleration and rank policy as stock AI Conflict Everon.

Requires AI Conflict Core, Arland integration, Everon integration,
AI Conflict Arland RHS, RHS Content Pack 01, RHS Content Pack 02 and
RHS - Status Quo. Tested with Reforger `1.8.0.13` and RHS `0.16.5150`.
This is a source release; the new addon has not been published to Workshop.

Workbench validation and five relevant static audits passed. The server
created all 20 groups, and a direct-connect client received replicated state.
The final server and client logs contain no VM/null errors. The full runtime
audit still fails on six previously documented RHS faction initialization
errors; other stock/RHS resource compatibility errors also remain. The
existing `AI_COMMANDER_UI_STATE` static failure is unchanged.
Visual checks, player deployment, the gameplay JIP/reconnect matrix,
long-duration testing and packaged Workshop validation remain pending.

See the [RHS Everon implementation and validation report](../RHS_EVERON.md)
for launch instructions, dependency IDs and detailed evidence.
