# 0.1.20

- Исправлено бесконечное ожидание промежуточной точки обхода: после прибытия лидера группа получает 30 секунд на завершение `ALL`, затем приказ к прежней цели восстанавливается. Таймер защищён от устаревших callback и смены группы; добавлена диагностика прибывших и отставших бойцов.
- Северные сценарии stock/RHS сохраняют два штаба и шесть точек захвата, включая Грабовую долину. Добавление лагеря у Ле Крю и электростанции отменено: у этих штатных entities нет компонента захвата. Проверка сценариев теперь проверяет наличие этого компонента.
- Состав ролей по умолчанию изменён на `6 ATTACK / 4 DEFEND / 0 RESERVE`. Управляемые боевые отряды и охрана FIA используют навык `EXPERT`.
- Добавлены вооружённые патрули FIA по радиографу; расширены экипировка ЧВК и варианты нашивок РФ, США и FIA. Нашивки различаются у бойцов одного отряда и сохраняются за ними.
- Ускорен поиск площадок строительства; строитель продолжает работу при боевой угрозе. Уточнены восстановление маршрутов, локальные аварийные перемещения и ожидание пополнения.
- Исправлены запоздалые AI callback, lifecycle support station, ранний arsenal RPC и повторные запросы загрузки navmesh. В RHS сохранены штатные дружественные связи фракций.
- Launcher запускает сценарии через `MissionHeader`, проверяет resource databases, точный server CLI и готовность сервера перед подключением клиента; исправлено чтение растущего UTF-8 лога.

Проверки текущих исправлений:

- Профильные static-аудиты — PASS; baseline failures в проверках маршрута и отката точек отсутствуют.
- Терминальный Workbench Validate/Compile — PASS для исправления маршрутов и восстановленных stock/RHS северных сценариев.
- Изолированная проверка таймаута маршрута — 16/16; изолированные stock/RHS проверки состава баз, компонентов захвата и радиографа — по 16/16, native exit 0.
- Полные остановленные серверные логи этих проверок не содержат SCRIPT E/F, ENGINE F и VM/null. Прежние native ошибки загрузки ресурсов сохраняются; весь runtime не объявляется свободным от ошибок.
- Боевой захват каждой восстановленной базы, client/JIP после отката, ручная визуальная проверка и packaged Workshop validation — NOT RUN. Эта версия публикует исходники в Git; Workshop upload не выполнялся.
